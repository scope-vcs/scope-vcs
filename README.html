Scope Share part of a repository.

Scope keeps public and private code in one Git repository. Contributors clone only the public paths, and accepted changes merge into the same history. This is Scope's own source, hosted on Scope.

adamblumoff/scope-vcsmain
  • api/server
  • cli/scope command
  • crates/domain and storage
  • web/browser app
  • worker/background jobs
  • runner-runtime/CI runner
  • README.md

Requests merge back.

A request starts as a private draft, opens for review, then merges or closes. It can't change private paths or .scope/RULES.md.

Run it locally.

$ cp .env.example .env.local
$ cp web/.env.example web/.env.local
$ ./dev/scope-dev up
$ ./dev/check

Add a Clerk development key pair to web/.env.local before starting the stack. docs/architecture.md explains how the code is organized.
