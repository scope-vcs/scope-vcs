# Code audit remediation

This table maps the 103 retained findings in the [published audit](https://web-production-4f13c9.up.railway.app/plans/scope-vcs/f2e06d6176) to their implementation and verification. The audited base commit is `eb4c3eac6c7ee86430c25b4ac8463da957cde161`. IDs retain the published order; related findings merged by that report remain covered by the retained entry.

Verification completed against PostgreSQL 16: the Rust workspace run passed 970 tests with two failures and two existing ignored experiments. The signal fixture's readiness race was corrected; all 16 process tests and 50 repeated signal checks then passed. The unchanged database-cleanup test passed on an idle cluster after checkpoint contention exhausted its timeout in the full run. Local-development and smoke-seed tests, workspace Clippy with warnings denied, and formatting passed.

Web verification passed 409 unit tests, type and architecture checks, production and worker builds, and all 50 browser smoke cases. Desktop/mobile and dark/light rendering were inspected. CLI verification passed 232 tests, lint, release build, a Linux installer smoke, and a real two-actor request/review/merge flow. Operational and policy gates passed, including cutover, baseline, migration immutability, source boundaries and sizes, and license inventory freshness. Native CLI checks also passed on Linux, macOS, and Windows in PR CI. Simple removals use existing behavioral tests and callsite inspection.

The required local autoreview was attempted with a 15-minute timeout. Its TruffleHog preflight stopped on a synthetic PostgreSQL URL in removed fixture content before the model ran; no clean model review is claimed.

The subsequent simplification removes duplicate heartbeat ownership, pass-through wrappers, and repeated test setup. Verification passed all 359 API tests, 18 focused PostgreSQL tests, 104 service tests, 406 web unit tests, and four consolidated browser journeys. One simplified database assertion was corrected to include both source and derivative reservations before passing its focused rerun. Both the original implementation and simplification passed all CI jobs. Review follow-up adds a shared native-history inspection deadline and removes unused frontend selector plumbing; all seven affected Git tests, 404 web unit tests, and web typechecking passed.
