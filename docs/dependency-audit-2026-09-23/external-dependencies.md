Versions are observations from September 23, 2026. “Keep” includes updating and narrowing configuration. Hosted services without versions are assessed from their use in this repository; their live configuration, cost and availability were not audited.

## Version ownership to fix

The most useful policy change is one reviewed version owner per runtime/tool, reused by images, tests and packaging. Git currently lacks one; Node and PostgreSQL have inconsistent consumers. `cross --locked` leaves the cross release floating. Python requirements leave transitive versions unresolved. Some GitHub actions and base images use mutable tags.

Keep the existing pnpm release-age and trust policies. Removing konsistent also removes the reason for its special release-age exception. Updating Node types may remove the reason for the undici-types exception. Revisit each exception after the graph changes instead of deleting policy wholesale.

This source audit does not enumerate every installed OS package, every browser shared library or every provider-side managed component. Those require SBOMs from the actual built/deployed images. The [locked package CSV](locked-dependencies.csv) does enumerate every external package entry in the four checked-in application lockfiles.
